# Build log

How this project was actually built, task by task — what each review found, what
was fixed because of it, and the decisions taken along the way. Kept because the
interesting part of a demo like this is not the finished pages but the defects
caught before they shipped.

The work ran as 14 planned tasks, each implemented, then reviewed against its
brief, then fixed where the review found something. The design spec and the
implementation plan it was built from live outside this repo and are not
published; this log stands on its own.

Entries are newest-first within each task. "Complete" means the task's review
came back clean.

## Shipped

Live at **https://store-demo-gv.fly.dev** (Fly, `store-demo-gv`, one shared-cpu-1x machine in `lhr`, suspend-on-idle). Source: **https://github.com/gabryelvs/store-demo** (public).

Vercel was the first target and got as far as a working deploy, then blocked the next one on a spend cap — the configurable limit is a Pro feature, so there was nothing to raise on Hobby, and Hobby also excludes commercial use, which this demo is. Moved to Fly: `output: "standalone"` + a three-stage Dockerfile, `images.unoptimized` since the photos are already cut to their rendered sizes. The Vercel project can be deleted whenever; it holds a stale build.

## 2026-09-23: static export on Cloudflare Pages

Dependabot flagged next 16.3.0 (2 critical, fixed in 16.3.3). The patch mattered on Fly because
the site ran a live Next server there, but Fly was blocking deploys over billing. Every route was
already prerendered, so the site now builds as a static export (`output: "export"`,
`trailingSlash: true`) and is served from Cloudflare Pages at https://demo.gabryelverissimo.dev.
Vercel's Hobby plan was ruled out again because it excludes commercial use. The Dockerfile,
.dockerignore and fly.toml are gone; the Fly app was deleted once the new site was verified.
Also patched: next 16.3.5, vitest 4.1.11, sharp 0.35.4, js-yaml 4.3.2 (npm audit: 0).
